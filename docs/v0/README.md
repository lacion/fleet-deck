# Fleet Deck v1 (v0 in the plan)

Fleet Deck v1 was the TypeScript daemon and board that observed Claude Code sessions through hooks. Version 2 replaces it. The v1 code, its documentation, its reviews and its changelog are not on branch `v2`.

- Read v1 on branch `main` (until the owner merges v2) or at the release tags `v0.*` (last release: `v0.23.6`).
- Before you move from v1 to v2, read [the cutover guide](../v2/cutover.md) and [the parity record](../v2/PARITY.md).
- The lessons from v1 that shape v2 are in [PLAN §4](../v2/PLAN.md).
