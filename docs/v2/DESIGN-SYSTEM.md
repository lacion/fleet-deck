# Fleet Deck design system ("Flight Deck", v3)

*Written 2026-10-22 on branch `ui-refresh`. The owner chose a mix of the concepts in `docs/v2/design/ui-refresh/concepts/`: the **look of A (Flight Deck)** with the **compact layout of B (Graphite)**. This file replaces the visual layer of `UI-DESIGN.md` (DL-141). The structure of `UI-PLAN.md` (sidebar, chat-first session, terminal dock, phone stack navigation) stays. The skill `.claude/skills/fleet-design-system/SKILL.md` tells every agent how to use this file and how to expand it. `tools/design-check.sh` checks the rules that a script can check.*

The reference pictures: concept A `docs/v2/design/ui-refresh/concepts/a/shots/*.png` (look, color, type, strips, approval card, composer, phone) and concept B `…/b/shots/*.png` (sidebar, density, list rows, properties panel, New session sheet, right ops panel).

## 1. Principles

1. **Calm deck, loud state.** The canvas is a quiet night deck. Color appears only where a state lives. Decoration has no color.
2. **One color, one job** (the carrier-deck jersey colors, §2.2). Yellow is *only* "needs you" and the primary button of a decision.
3. **Every session is a strip.** A status holder at the left edge, fields divided by thin rules. Strips are the signature of the board; use them for sessions everywhere (fleet, sidebar, needs-you, phone).
4. **Compact on a desktop, roomy on touch.** Desktop rows 36–44 px, controls 28 px. Touch (`pointer: coarse`) controls 44 px.
5. **Mona Sans for words, mono only for code.** The width axis carries meaning: condensed = callsign, wide = place (station names, page titles). JetBrains Mono only for paths, branches, commands, code, diffs and ids. Never mono for times, counts, models or labels.
6. **Depth from fills, not borders.** Surfaces step up in lightness. A 1 px rule only divides fields of a strip and sections. No box inside a box.
7. **Show what is known.** No "unknown", no empty labels: a missing value is an absent element (DL-141 rule 4 stays).
8. **Sentence case.** No all-caps labels, no letter-spaced capitals.

Rules:

- **Yellow is never decoration**: not the logo, not New session, not a selected tab, not a focus ring (the focus ring is `--focus`).

- A **general primary** button (New session, Start session, Save, Queue follow-up) is a solid ink button: `--ink-fill` with `--ink-on` text. ### 2.5 Elevation and motion

- `--shadow-pop`: dark `0 1px 0 rgba(255,255,255,.04) inset, 0 16px 40px rgba(0,0,0,.45)`; light `0 12px 32px rgba(17,24,33,.12)`. Only on floating layers: menus, dialogs, popovers, the approval card, the composer, toasts, bottom sheets.
- `--scrim` *(new)*: dark `rgba(6,10,15,.6)`; light `rgba(17,24,33,.28)` — the one dim layer behind every dialog, the drawer and a sheet.
- `--shadow-lift` *(new)*: dark `0 0 0 0 transparent`; light `0 1px 2px rgba(17,24,33,.07)` — strips and cards in the light theme.
- A shadow token (`--shadow-lift`, `--selected-lift`, `--knob-shadow`) is **never `none`**: area rules put it in a `box-shadow` list (`inset 3px 0 0 var(--ok), var(--shadow-lift)`), and `…, none` is invalid, so the browser drops the whole declaration. "No shadow" is the zero shadow `0 0 0 0 transparent`.
- `--t-fast` 120ms ease-out (hover, press), `--t-move` 200ms ease (expand, slide), `--t-drawer` 220ms ease-out.
- A theme change is one step: every write of `<html data-theme>` (the Appearance choice, the System scheme at sunset, forced colors, an Omarchy palette) sets `<html data-theme-switching>` for two frames (`main.tsx`), and `base.css` stops every transition while it is set. Without it the buttons, tabs and segments faded for 120ms through the old theme while the page changed at once (near-white text on white).
- `--pulse-needs` 2400ms: the needs-you glow breathes (opacity of the glow only). `--pulse-working` 2400ms: the working glyph arc turns. Nothing else moves without a user action. `@media (prefers-reduced-motion: reduce)` stops every animation, and so does the board preference **Reduce motion** (`ui/theme.ts`, stored next to the theme choice; it sets `<html data-motion="reduce">`, and `base.css` applies the same stop), so that a user can pause the two breathing states without the OS setting (WCAG 2.2.2).

### 2.6 Logo *(new)*

- **The mark** is one path on a 24-unit box (`MARK_PATH` in `web/src/ui/brand.ts`, even-odd fill). Concept C "Formation": five rounded squares in a V, the deck in the lead. It has one color: on the board `currentColor` with `color: var(--text)` (`ui/Mark.tsx`, `.fd-mark`). Never yellow, never a semantic color, never on a tile on the board, never outlined, rotated or stretched.
- **Sizes:** 16px is the smallest. The board uses 24px (brand row, phone and tablet top bars), 32px (login, wall pairing) and 20px (wall corner, zoomed with the wall).
- **The wordmark** is the text "Fleet Deck" in Mona Sans, width 115 %, weight 620 (`.fd-wordmark`, the `.fd-wide` cut), sentence case, letter spacing 0. On the board it is live text; in images it is rendered from the bundled font.
- **The lockup** is the mark, then the wordmark on the same centre line. The mark box is 1.7 times the font size of the wordmark, and the gap is a third of the mark box (the brand row: 24px, 8px, 14px). Keep a clear space of half the mark box around a lockup.
- **Tiles** only outside the board: app icons, the favicon fallback and the social preview use the mark in `#E9EEF4` on a `#111821` tile (the dark `--text` on the dark `--bg`). `tools/brand/render.mjs` makes every brand file from `MARK_PATH`; never edit a brand PNG or SVG by hand.

## 4. Components

### 4.1 The strip (session row)

```
┌─┬────────────┬─────────────────────────────────────┬──────────────────┬─────────┬──────┐
│▌│ otter-n1rr │ Fix flaky shim test   ▲ Bash cargo… │ ⎇ fleet-sync     │ +9 −3   │ 2 min│
└─┴────────────┴─────────────────────────────────────┴──────────────────┴─────────┴──────┘
 holder callsign  title (600) + now (dim, tool icon)   where (mono 12px)  changes   age
```

- `--raised` fill, `--r-card`, height `--strip-h` (44px), 1px `--border` vertical rules between fields, the `.fd-holder` at the left edge. Light theme adds `--shadow-lift`.
- Callsign cell 104px: `.fd-callsign` 14px `--text` over the model (12px `--dim`) — or one line (callsign only) when the strip is one line.
- Title 14px weight 600; the "now" text (current tool icon + name + mono target, or focus line) in `--dim` on the same line after the title, truncated with an ellipsis.
- Changes: `+142` `--ok`, `−37` `--hazard`, 12px weight 600; the files count (`countText`: `1,286 files`) `--faint`. The column is `--fd-changes-w` (112px): it holds a diff of 12 characters (`+12,345 −678`); a longer diff takes the short form of §5 (`+18K −6.4K`), and the title keeps the whole numbers ("Changed since the session started: +17,583 −6,386").
- Chips that are links of their own (PR, issue, project, batch compare): `.fd-badge` with a Lucide icon, in the second line of the where cell. Counters and flags of the session (mail, agents, artifacts, background commands, terminal, permission mode, conflict, archived, stale) are the quiet form `.fd-strip-ico` in the meta cell: a 12px Lucide icon and the count (12px `--dim`; a hazard flag `--hazard`), with no fill. Each one is `role="img"` with an accessible name ("Agents running: 2"), because the strip is a link. "Agents running" counts the subagents and the running workflow agents; when the count is a lower bound (a workflow that the session does not follow) the number reads "3+" (also "0+") and the title adds "Some workflow agents are not counted." "Background commands" counts the background tasks that are neither agents nor workflows and hides at 0. The hazard flags (permission mode, conflict) come last, so they sit against the where cell in every strip and a lane reads its risky sessions down one column; the permission mode flag is named with `modeLabel` ("Permission mode: Bypass permissions"). When two or more live strips of a lane share one risky mode, the lane head names it once (§4.4) and those strips drop the flag (its words stay for screen readers, `.fd-vh`); a strip whose mode differs keeps its flag.
- **Order in a lane**: starred first, then the status rank (needs you, working, verifying, queued, idle, unreachable, lost, ended), then the arrival in the status, newest first: a strip keeps its place while its session works and moves only when its status changes; a new session comes first in its group (`stripCards`; the one record of the board, `BOARD_ARRIVALS` and `rememberArrivals` of `board/fleet.ts`, which the sidebar rows and the j/k keys read too).
- Hover `--raised-hi`. Selected (the open session): `--raised-hi` + 1px `--focus` outline. A selected needs-you card shows its selection as a 2px inset `--focus` ring inside the `--act-line` outline (fine pointer only, never on the phone), with no tint.
- **Needs you**: holder `--act`, 1px `--act-line` outline, `--act-glow` glow (breathing), the request text in `--act`, inline action buttons (`.fd-decide` Allow with kbd `a`, Deny ghost danger with kbd `d`, or the question's options). The other plain answers have a `--raised-hi` fill and a 1px `--ctl-edge` edge on hover. In a station lane under the Needs you panel, the needs-you strip has the holder, the 1px `--act-line` outline and the yellow request text; the breathing glow is the panel's (one glow for one request on the screen).
- **Cleared (archived)**: no fill, a 1px inset `--border-soft` edge, title weight 500; the text keeps the `--faint` of an ended strip. Never opacity: a dimmed text falls under 4.5:1.
- The lane activity sparkline is a data graphic: bars `--faint` (3:1 or more), the last bar `--ok`.
- **Ended/lost**: text `--faint`, holder hollow.
- Below 900px the strip becomes two lines (title line, meta line) and drops the field rules, and the project of the session is a dim 12px label with the `folder-git-2` icon at the start of the meta line (no third line); the status glyph hangs in a column of its own: the first cell of the second line (the callsign; in a repo or project lane the station) starts under the title, so the two lines share one left edge; the links row keeps only PR, issue and compare chips. Under 480px (a phone) the facts (the project label, at most 96px, the counters and the flags) move up to the title line before the age, so the second line gives the callsign and the now text all the room.
- The where column is `--fd-where-w`: 168px, on a wide board 16% of the fleet column up to 260px. The changes column (`--fd-changes-w`) is a choice of the board (all lanes or none), so every where cell starts at one x; once shown, it stays until the page reloads (`.fd-board[data-changes]`): a live event never moves every where cell of the board. The Sessions tab of a project makes the same choice for its live list and its Ended fold (`.fd-int-tab[data-changes]`).
- Unread on a strip or a sidebar row is a 6px `--focus` dot (`.fd-count[data-tone=info][data-shape=dot]`; the count is in its name, "3 unread"); a Watch tile keeps the info pill with the number.

## 5. Copy

Sentence case; plain verbs; one name per action across a flow (Allow → "Allowed"). Times: "2 min", "14 min", "2 h", "1 d". Counts: "3 of 12". No "unknown". Errors say what happened and what to do.

**Numbers.** One kind of number has one format on every surface, from one helper of `ui/format.ts` (never `toFixed`, `toLocaleString` or a local formatter in a component):

| Kind | Helper | Examples |
| --- | --- | --- |
| a count (events, files, lines) | `countText` | `940`, `1,286`, `Events 7,405` |
| the lines of a diff | `addedText`, `removedText` | `+1,286` `−400` (U+2212 minus) |
| the lines of a diff where room is short (the strip changes column, over 12 characters) | `+`/`−` and `compactCount` (FleetStrip `diffTexts`) | `+18K` `−6.4K` (the title keeps `+17,583 −6,386`) |
| a large count where room is short (tokens) | `compactCount` | `940`, `9.4K`, `236K`, `1.3M` (two significant digits, no trailing `.0`, no space before K or M: `236 k out` read as a word) |
| money | `usdText` | `$1.20`, `$14,876.41` (separators and cents everywhere, so that every cost reads the same) |

**Counts after a label.** A count after a label (a nav row, a group, a tab, a filter, a button: Ended, Archived, Resume all, Clear, Filters) is a `.fd-count` pill after the label: `Archived` and the pill `31`. Never `Archived (31)`: two notations for one thing. The accessible name is the label and the number ("Resume all 2"); a pill whose number alone is unclear adds a `.fd-vh` word. A count of zero on a disabled button shows no pill. A count of hidden items after a label is a `+N` pill (`CPU by session` and `+2`, its `.fd-vh` "more sessions"): a bare number next to the items in view read as their total.

**Paths.** A shown path starts at its root: `~/projects/app` under a home folder (`homeShort`; inside a command or a tool target `homeShortIn`: `cat ~/a.txt`), else `/srv/data`; never a root-less `home/me`. A folder row shows its name and its parent (`pathParts`: `v2` and `~/fleet-deck-worktrees/`, the parent in `--faint` mono 12px with an ellipsis) and the full path in its `title`. Copy actions copy the full path.

**Modes.** A permission mode has one name on every surface (session header, Properties, New session, the fleet access forms, settings, Automations): `modeLabel` of `ui/format.ts`. Claude: `Accept edits`, `Don't ask`; Codex (`<approval>/<sandbox>`): `Ask when needed · workspace write`, `Ask for untrusted commands · read only`, `Never ask · full access`. The option value and the `title` keep the id.

**Sizes.** A size of a station (disk, memory, a session's memory, the wall row) is `bytesText` of `board/resources.ts`: whole MB under 1 GB, one decimal GB under 100 GB, whole GB under 1 TB, then TB with up to two decimals (`340 MB`, `46.8 GB`, `864 GB`, `1.08 TB`). One exception: the memory of a wall station row is whole GB as a count, `Memory 9 of 47 GB` (a glance from across the room needs no decimal; `wall/stationStats.ts`); its disk stays `bytesText`. A file size is `sizeText` of `ui/format.ts`.

**Platforms.** The architecture of a station is the name that owners know, from `archLabel` of `ui/format.ts`: `aarch64` (the Rust target name) and `arm64` are `arm64`, `x86_64` and `amd64` are `x86_64`; any other value stays. `macOS · arm64`, `Linux · x86_64`. The `title` keeps the raw value.

**Models.** A model is its family and version: `Opus 5.5` (`shortModel`). The context window is a fact of its own, `1M context` (`contextLabel`), an aside of the Properties Model row; a bare `1M` after the version read as a version or a count. The `title` keeps the raw id.

**Cost.** A session cost is the price at the provider's API rates, cached input included: its label is "at API prices" ("At API prices" at the start of a label), never "cost", and its title says what it is (`API_PRICES`, `apiPricesTitle` of `board/usage.ts`; the fleet glance, the strips, Properties, Compare and the wall race). A cost that the station does not report is absent.

**Tools.** A tool call reads in the words of one parser (`toolParts` of `watch/tooltext.ts`), for the chat rows, the request lines, the Watch and wall tiles and the Activity rows: an MCP tool in words with its server apart (the deck's own server is none), a built-in id that is not a word in the words of `BUILTIN_WORDS` (`AskUserQuestion` → Question, `TodoWrite` → To-do list, `WebSearch` → Web search); the raw id stays in the `title`.

## 6. Accessibility floor

Text 4.5:1 (large text and icons 3:1) in both themes and with an Omarchy palette (`ui/palette.ts` computes the palette tokens and steps them until they pass: every text token 4.5:1 on `--raised-hi` and on every tint, `--act-bg`, `--hazard-bg`, `--ok-bg`, `--fuel-bg`, `--focus-bg`; `--ctl-edge` 3:1 on `--raised-hi`; `--act-line` 3:1 on `--bg`, `--raised` and `--act-bg`); focus visible on every control (`--focus` 2px outline); state never by color alone (glyph shapes, holder + text); touch targets 44px; `prefers-reduced-motion` and the board preference Reduce motion honored (§2.5); every icon-only button has an `aria-label`. In forced-colors mode (Windows High Contrast) the page takes the theme of the OS color scheme (`prefers-color-scheme`), not the stored choice or an Omarchy palette (`resolvedTheme()` in `ui/theme.ts`): the kept glyph colors below are made for their own theme, and a dark `--act` on a white `Canvas` is 1.43:1. `base.css` keeps the glyphs, holders, slots and meters in their own colors (`forced-color-adjust: none`); gives a `Highlight` ring to the pressed segment, chip and toggle (any `aria-pressed=true` button), the selected tab (`[role=tab][aria-selected=true]`), the selected option of a list box (`[role=option][aria-selected=true]`), the current nav or session row (`[aria-current=page]`), the current subagent row (`[aria-current=true]`), the open integration row (`.fd-selbar[data-open=true]`) and the needs-you keyboard cursor (`.fd-q[data-selected=true]`); draws the switch and a checked checkbox or radio in `Highlight`/`HighlightText`; draws the summary chevron in `CanvasText` and the select chevron as an `url()` image; gives key hints, badges, counts and the avatar a 1px `CanvasText` edge; keeps `.fd-primary` and `.fd-decide` solid (`ButtonText` fill, `ButtonText` edge, `ButtonFace` text and key hint; not `Highlight`, which marks the selection and the focus), so that one primary still stands out of a row of plain buttons; gives the ghost select a `ButtonText` edge and a segmented control (`.fd-seg`) a 1px `ButtonText` group edge. An unselected underlined tab (session pane tabs, settings tabs) has no rule in forced colors: only the selected tab is marked. An area part whose edge or selection is only a `box-shadow` or a fill adds its own `@media (forced-colors: active)` rule. The chat flight path (its line and nodes) keeps its own colors (`forced-color-adjust: none` in chat.css), so that a filled node and a ring still differ by fill. Check it with Playwright `page.emulateMedia({ forcedColors: "active" })`.
